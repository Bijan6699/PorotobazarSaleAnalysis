KIAN DASHBOARD - PORTABLE PACKAGE
==================================

This folder contains:

1. Setup.bat  - ONE TIME ONLY. Double-click to install Python (if needed)
   and all required libraries. You need internet connection for this.
   Run it once, then never again.

2. Run.bat    - DAILY USE. Double-click to start the dashboard in your
   web browser. Close the black window to stop the app.

3. Build-EXE.bat  - OPTIONAL. Builds a standalone EXE in the dist folder
   (Run.bat does not need this). The EXE works only on 64-bit Windows.
   You still need app.py next to the EXE.

To share this app with another computer: copy this whole folder,
run Setup.bat once on the new computer, then use Run.bat.
