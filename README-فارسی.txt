داشبورد کیان - پکیج قابل حمل
=============================================

این پوشه شامل فایل‌های زیر است:

۱. Setup.bat — فقط یک بار اجرا کنید. با دابل‌کلیک، پایتون (در صورت نبود) و
   همه کتابخانه‌های مورد نیاز را نصب می‌کند. برای این مرحله به اینترنت
   نیاز دارید. بعد از یک بار اجرا، دیگر لازم نیست.

۲. Run.bat — استفاده روزانه. با دابل‌کلیک، داشبورد در مرورگر باز می‌شود.
   برای بستن برنامه، پنجره سیاه را ببندید.

۳. Build-EXE.bat — اختیاری. یک فایل EXE مستقل در پوشه dist می‌سازد.
   (برای استفاده از Run.bat نیازی به این کار نیست.) فایل EXE فقط روی
   ویندوز ۶۴ بیتی کار می‌کند. فایل app.py باید کنار EXE باشد.

روش اشتراک‌گذاری: کل این پوشه را روی کامپیوتر دیگر کپی کنید، یک بار
Setup.bat را اجرا کنید و سپس هر روز با Run.bat برنامه را اجرا کنید.
